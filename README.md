### Instructions (for now)
- Set up mysql (I used mariadb). Make the root password `changeme`.
- Create a database named `cellarconstitution` on your machine.
- Maybe you have to do `npm install [some dependences]` for both the backend and client.
  - `npm install mysql2 express cors` for backend
  - `npm install axios react-router-dom` for client
- Run `npm start` on both client and backend.
- Visit `http://localhost:8080` for the backend, and `http://localhost:3000` for the frontend.


I followed this tutorial: https://www.youtube.com/watch?v=fPuLnzSjPLE
